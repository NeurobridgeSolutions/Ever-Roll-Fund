# Claude Code rules for this repository

These rules apply to every Claude Code session on this repo, for every team member.

## What this repo is

- The public website for Ever Roll Fund, a 501(c)(3) nonprofit (index.html, apply.html, accessibility.html).
- **This repository is PUBLIC on GitHub.** Anything committed here can be read by anyone.

## Never commit to this repo

- NeuroBridge Solutions (NBS) or Funding Finder pricing, fee ranges, negotiation ranges, or contract values.
- Anything internal or marked "Confidential": investor materials, customer lists, contracts, financials.
- API keys, passwords, tokens, or patient or applicant data (including real form submissions).

## Writing style

- Never use em dashes. Use a regular hyphen (-) or an en dash instead. This applies to site copy, commit messages, and PR descriptions.
- Keep copy direct and concise. Lead with the key point.
- Every claim or statistic must have a source. Do not publish unsourced numbers.
- Flag weak ideas and assumptions instead of agreeing by default.

## Facts that must stay accurate

- Grant funding flow: all grant money from any foundation or nonprofit is paid directly to the manufacturer, never to the individual patient. State this exactly whenever the funding flow is described.
- Kortlund Natterstad's background: 12+ years in medical device sales, primarily in ENT. That work had no connection to spinal cord injury. Never imply otherwise.
- Use full names on formal content: Natalia Natterstad (Co-Founder & CEO, NBS) and Kortlund Natterstad (Co-Founder & COO, NBS).
- NeuroBridge Solutions is a Florida C-Corp based in Fort Myers, FL. Ever Roll Fund is a separate 501(c)(3) nonprofit. Do not blur the two.
